# 🌐 Portfólio de Desenvolvimento Web

Este repositório contém meu **portfólio virtual de desenvolvimento web**, criado com o objetivo de colocar em prática, testar e aperfeiçoar meus conhecimentos em **HTML e CSS**.

Mais do que apenas um portfólio, este projeto funciona como um espaço para registrar minha **evolução no aprendizado**, reunindo projetos, estudos, cursos, exercícios, experimentos e outros conteúdos relacionados ao desenvolvimento web.

> 🚧 **Projeto em desenvolvimento:** este portfólio será atualizado constantemente conforme eu avanço nos meus estudos e adquiro novos conhecimentos.

---

## 🎯 Objetivo

O principal objetivo deste projeto é criar um ambiente onde eu possa:

- 🧑‍💻 Praticar desenvolvimento web;
- 📚 Registrar meus estudos e aprendizados;
- 🛠️ Testar diferentes recursos de HTML e CSS;
- 📝 Aplicar na prática os conceitos aprendidos nos cursos;
- 🎨 Aperfeiçoar minhas habilidades de criação e estilização de páginas;
- 📱 Desenvolver páginas responsivas;
- 🚀 Criar e adicionar novos projetos ao longo do tempo;
- 📈 Acompanhar minha evolução como desenvolvedor.

---

## 💻 Tecnologias

Atualmente, as principais tecnologias utilizadas e estudadas neste projeto são:

- **HTML5** — Estrutura e semântica das páginas;
- **CSS3** — Estilização, layout, responsividade e apresentação visual.

Conforme meus estudos avançarem, novas tecnologias poderão ser adicionadas ao projeto.

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web.

A ideia é utilizar o portfólio não apenas para apresentar o que já aprendi, mas também como um **laboratório pessoal**, onde posso experimentar diferentes soluções, cometer erros, encontrar maneiras melhores de desenvolver e acompanhar minha evolução.
